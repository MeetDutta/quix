# Git Workflow Rules for EduQuizX

Whenever performing git commits and pushes for this repository:

1. **Meet Branch Targets**:
   - Push to the `meet` branch of:
     - `edgenmedia` (`https://github.com/edgenmedia/EduQuizX.git`)
     - `quiz` (`https://github.com/MeetDutta/quiz.git`)
     - `origin` (`https://github.com/MeetDutta/quiz.git`)
   - Do NOT push the `meet` branch to `quix`.
   - Do NOT merge `main` into `meet`.

2. **Main Branch Target**:
   - Push to the `main` branch of:
     - `quix` (`https://github.com/MeetDutta/quix.git`)
     - `origin` (`https://github.com/MeetDutta/quiz.git`)
