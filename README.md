# AI Dynamic Examination & Student Management System

A high-fidelity, enterprise-grade AI-powered SaaS assessment platform featuring **FastAPI**, **Next.js 15 (App Router)**, **SQLite/PostgreSQL**, and **Google Gemini RAG** pipeline.

---

## Technical Stack
- **Backend**: FastAPI (Python 3.9+) with SQLite DB fallback and Websocket/Proctoring logs alerts.
- **AI RAG Pipeline**: In-memory persistent Cosine Similarity vector database, using Gemini API `text-embedding-004` and `gemini-1.5-flash` for chunk search, objective/subjective grading, citations, and blueprints assembly.
- **Frontend App Router**: Next.js 15 (App Router), React 19, Tailwind CSS v4, and Zustand stores.
- **Developer Playground (Served by FastAPI)**: Self-contained static developer playground client served directly by FastAPI. Enables instant manual verification of all RAG uploads, CSV updates, student credential exports, live secure test engines, copy-paste tab-switch proctor alerts, and subjective AI booklets grading.

## 📖 QuickStart & Execution Guide

For complete step-by-step instructions on running, testing, and operating all features of this application, please refer to the **[Running Guide](file:///Users/meet/Desktop/quiz_application/RUNNING_GUIDE.md)**.

### Quick Start Summary

1. **Terminal 1: Start Backend (FastAPI)**
   ```bash
   cd backend
   source ../venv/bin/activate
   python -m uvicorn app.main:app --reload --port 8000
   ```

2. **Terminal 2: Start Frontend (Next.js)**
   ```bash
   cd frontend
   npm run dev
   ```

3. **Access Portals**:
   - **Teacher Studio**: [http://localhost:3000](http://localhost:3000) (`teacher@aegeus.edu` / `securepassword`)
   - **Student Portal**: [http://localhost:3000/dashboard/student](http://localhost:3000/dashboard/student) (`student@aegeus.edu` / `securepassword`)
   - **API Documentation**: [http://localhost:8000/docs](http://localhost:8000/docs)
   - **Health Status**: [http://localhost:8000/health](http://localhost:8000/health)

## Verification Playground

Once the FastAPI server is running:
1. Open your browser and navigate to **`http://localhost:8000/static/index.html`**.
2. **Tab 1: Student Directory**: Create students manually or review the roster.
3. **Tab 2: Knowledge Base**: Upload a PDF or textbook. The server chunks and vector-indexes the document content immediately.
4. **Tab 3: Exams Builder**: Assemble a new exam using the blueprint constructor. Click **Publish** to generate a direct quiz link.
5. Click **Gen Session Creds** next to the published exam, then copy the username and password details.
6. Open the **Direct Exam Link** (or go to `http://localhost:8000/static/exam.html?code=YOUR_EXAM_CODE`).
7. Enter the dynamic username and password to log in.
8. Answer questions. To test proctoring alerts: open the developer console, resize the window, or shift browser tabs. These events are immediately logged to the DB.
9. Click **Submit Exam**.
10. Go back to the Teacher Console dashboard, open **Gradebook Analytics**, click **View Booklet** for the student, and review the scores and detailed subjective grading comments generated by the Gemini AI.
