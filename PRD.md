# EduQuizX — Product Requirements Document (PRD)

## 1. Executive Summary
**EduQuizX** is an enterprise-grade, AI-powered examination, assessment generation, dynamic question studio, live anti-cheat proctoring, and student learning analytics SaaS platform. Designed for schools, universities, and corporate training institutions, it automates the end-to-end assessment lifecycle from syllabus ingestion to automated grading.

---

## 2. Target Personas & Roles

### 2.1 Instructors / Teachers (`teacher`, `inst_admin`, `super_admin`)
- Upload syllabus documents, textbooks, lecture slides, and notes into dedicated subject Knowledge Bases.
- Configure exam blueprints (duration, marks, negative marking, question type distributions, difficulty).
- Use the **AI Question Studio** to review, edit stems/options/marks, insert custom questions, and re-roll individual questions via AI.
- Publish assessments, schedule testing windows, generate unique candidate passcodes, and export CSV rosters.
- Monitor active candidates in real time via the **Live Anti-Cheat Proctoring Command Center**.
- Analyze cohort score distributions, pass rates, topic mastery heatmaps, and export comprehensive gradebooks.

### 2.2 Student Candidates (`student`)
- Securely log in using institutional credentials or single-session exam passcodes.
- Access the **Student Portal** showing active, scheduled, and past assessments.
- Undertake assessments in a locked, distraction-free, anti-cheat exam room.
- Review detailed post-exam evaluations with KaTeX mathematical formulas, correct answer keys, and AI learning diagnosis.

---

## 3. Key Functional Modules

### 3.1 RAG Knowledge Base & Document Ingestion
- **Supported Formats**: PDF, DOCX (with table extraction), PPTX (with notes & shapes), TXT, CSV, MD, JSON, source code, and Images (OCR via Gemini Vision).
- **100% Whole-File Preservation**: Extracts all pages, slides, tables, and paragraphs with zero arbitrary truncation.
- **Vector Indexing**: Chunks text with overlapping boundaries and indexes embeddings for semantic similarity search.

### 3.2 Dynamic AI Assessment Generator
- Generates balanced Multiple Choice Questions (MCQ), True/False, and Subjective questions grounded strictly in the subject's Knowledge Base.
- Strict count adherence: Slices exact requested questions (`raw_questions[:count]`) to prevent counter overshoots.
- Formula & Symbol Preservation: Supports KaTeX / LaTeX formatting (`$...$` and `$$...$$`) for scientific and mathematical notations.

### 3.3 Interactive AI Question Studio
- Pre-publishing interactive modal allowing inline editing of question text, option choices, correct answer designations, and marks allocation.
- **Single-Question AI Re-Roll**: One-click regeneration of individual questions using Knowledge Base context.
- Custom question addition and single-question deletion.

### 3.4 Security & Live Anti-Cheat Proctoring
- **Isolated Exam Sandbox**: Fullscreen enforcement, tab-switch detection, copy-paste prevention, developer tools blocking, and window defocus tracking.
- **Live WebSocket Feed**: Real-time event streaming (`/api/v1/attempts/ws/teacher/{exam_id}`) broadcasting red-flag alerts to teachers.
- **Remote Exam Termination**: Teachers can trigger "End Assessment Early" to close testing windows instantly.

### 3.5 Automated Grading & Student Analytics
- Instant grading for objective questions (MCQ / True-False) with configurable negative marking.
- AI evaluation of subjective answers against rubrics.
- Dynamic learning diagnosis generated by Gemini AI identifying strengths, weaknesses, and revision roadmaps.
- Cohort leaderboards and topic-by-topic mastery tracking.

---

## 4. Non-Functional Requirements
- **Response Time**: API queries < 200ms; AI question generation < 8s.
- **Security**: JWT authentication, bcrypt password hashing, role-based endpoint protection.
- **Reliability**: Cascading database transactions ensuring zero orphan foreign keys.
- **Accessibility & Aesthetics**: Warm aesthetic design system with full dark/light theme switching and responsive mobile/desktop layouts.
